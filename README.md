# SENTINEL
## Cyber-Threat, Vulnerability & Exploitation Monitor

A light-theme, always-fresh public data dashboard tracking confirmed in-the-wild exploitation (CISA KEV), EPSS exploitation probabilities, and extortion leak site claims.

### Core Invariants
1. **CVSS != EPSS != KEV:** Severity, probability, and active exploitation are isolated. Zero composite blended scores.
2. **Mandatory Issuer Attribution:** Every score renders with its issuing body and metric version.
3. **Ransomware Claims Caveat:** Extortion claims reflect publication behaviour on criminal leak sites, not confirmed breach counts.
4. **No Weaponised Exploits:** Zero offensive payloads or attack instructions.
